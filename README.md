# UAB THE HACK! 2026

Repositori de l'equip per al hackató (ds 7-11 8:00 → dg 8-11 15:00, Escola d'Enginyeria UAB).

Treballem en un sol ordinador: l'equip decideix junt, Claude orquestra i integra, i tres subagents de Codex (ChatGPT) programen per rols (frontend, backend i dades).
