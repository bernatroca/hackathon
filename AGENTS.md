# Norma per a tots els agents (Codex i altres)

Per indicació de la direcció del repte, cap agent llegeix les dades reals.

- No llegeixis `repte/`, `resultats/` ni `dades/`, ni amb eines de lectura ni amb ordres (`cat`, `head`, `python -c`…).
- Treballa amb l'esquema i les files inventades de `docs/esquema-dades.md`.
- Pots executar el codi del projecte sobre les dades (`python -m nivell1.comprova`, el verificador, les proves), però **no imprimeixis mai files de dades**. Només recomptes, errors o el veredicte.
- Si per fer la feina necessites veure una fila real, para i torna STATUS QUESTION explicant per què.
